POP3 — Post Office Protocol v3
Port 110 · Download-and-delete model
MAIL SERVER

↓

• Messages downloaded to local device
• Server copy typically removed after RETR+DELE
• No cross-device synchronization
• Simple but stateful on a single client
IMAP — Internet Message Access Protocol
Port 143 · Server-side state model
MAIL SERVER
↕
IMAP SYNC
↕

• Messages remain on the server
• Flags (read/unread/flagged) synchronized
• Multiple devices see same state
• Folder hierarchy supported

MailFlow X

Interactive Email Protocol Failure & Recovery Simulator

MailFlow X is an educational network laboratory for exploring the application-layer protocols that power email delivery. It simulates SMTP, POP3, IMAP, DNS and TCP entirely in the browser — no real emails, credentials or external servers are ever used.

Protocols
  • ▸ SMTP — RFC 5321
  • ▸ POP3 — RFC 1939
  • ▸ IMAP — RFC 3501
  • ▸ DNS — RFC 1035
  • ▸ TCP — RFC 793
Features
  • ▸ Live topology animation
  • ▸ Failure injection lab
  • ▸ Protocol X-Ray inspector
  • ▸ Replay timeline
  • ▸ Automatic diagnosis
Constraints
  • ▸ No real email delivery
  • ▸ No external services
  • ▸ No credentials required
  • ▸ Fully client-side
  • ▸ Offline-capable
